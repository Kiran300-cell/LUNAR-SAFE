LUNAR-SAFE is a research dashboard for lunar digital elevation models. Explore the V12 evaluation, compare reconstruction methods, and interactively screen projected DEMs using slope and local roughness thresholds.

View project on GitHub Open the LUNAR-SAFE Dashboard

Interactive terrain screening

Adjust slope and roughness limits and see pass-proxy, review, and high-priority map classes update with the uploaded DEM.

Reproducible model evaluation

Inspect held-out patch results for bicubic, bilinear, CNN-A, and CNN-B, including uncertainty and training histories.

Research exports

Download analysis metadata, detailed workbook sheets, and an evaluation report from the dashboard.

Research scope

The included V12 benchmark uses synthetic 5× degradation in one lunar region. It does not include independent real 5 m validation. DEM vertical units are unconfirmed, so slope and hazard classes are conditional exploratory proxies.

Scientific caution: LUNAR-SAFE is a research prototype. Its outputs are not certified landing-safety assessments and should not be used as mission approval.

Run the dashboard

Clone the repository, install dependencies from requirements.txt, and run python -m streamlit run app.py. For a public interactive deployment, connect the repository to Streamlit Community Cloud. GitHub Pages hosts this searchable project page; it does not run the Streamlit application.
